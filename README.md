# ENKI Playbook para Arquitectos

Guia interactiva para arquitectos y disenadores que quieren vender una linea propia de mobiliario personalizado usando ENKI como respaldo productivo, digital y tecnico.

## Que incluye

- Navegacion por bloques del modelo operativo ENKI.
- Flujo de captacion, estimado, moodboard, levantamiento, diseno, cotizacion, produccion, entrega y garantia.
- Prompts editables por bloque para trabajar con modelos de AI.
- Calculadora de moodboard al 1% del valor estimado.
- Calculadora mensual de rentabilidad para negocio llave en mano.

## Archivos principales

- `index.html`: estructura de la experiencia interactiva.
- `styles.css`: estilos visuales y responsive.
- `app.js`: contenido de bloques, prompts, calculadoras e interacciones.

## Como abrirlo localmente

Puedes abrir `index.html` directamente en el navegador o servir la carpeta con un servidor local.

```bash
python -m http.server 4180
```

Luego abre:

```text
http://127.0.0.1:4180/
```

## Enfoque del modelo

El arquitecto atiende, vende y lidera al cliente final. ENKI acompana al arquitecto como sistema de cotizacion, diseno tecnico, fabricacion, entrega e instalacion si aplica.
